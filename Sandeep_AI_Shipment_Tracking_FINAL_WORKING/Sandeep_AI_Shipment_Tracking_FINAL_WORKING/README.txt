SHIPMIND AI - FINAL WORKING VERSION

Created for: Sandeep

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in Google Chrome or Microsoft Edge.
3. Click the sidebar items. All pages are inside index.html and connected to assets/js/app.js.
4. No server, API key, database, or installation is required.

WORKING FEATURES
- Dashboard
- Shipment search and filters
- New shipment creation
- Detailed live shipment tracking
- Tracking ID, customer, phone, location, vehicle, driver, package, weight, value, origin, destination and progress
- AI Analytics
- Text-to-chart demo
- AI Assistant
- AI Search / natural-language query
- AI Copilot
- AI Content Generator
- AI Document Summarizer
- AI Report Generator
- Notifications
- Team Management
- Settings
- Command Palette / Ctrl+K
- Dark/light theme
- Responsive mobile layout
- Animated cursor, hover, route and card effects

IMPORTANT
This is a frontend demonstration. AI answers and shipment data are simulated locally; there is no real logistics backend/API.

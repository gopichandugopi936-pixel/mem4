# Royal Enfield 3D Analytics Dashboard

Pages:
1. Dashboard
2. Sales Analytics
3. Customer Analytics
4. Model Analytics
5. Marketing Analytics
6. Financial Analytics
7. Real-time Analytics
8. Reports & Export

3D/visual effects:
- 3D perspective hero panel
- 3D hover cards
- 3D model cards
- animated custom cursor
- glow and lift effects
- glass/gradient panels
- responsive design
- dark dashboard theme

Year filter:
Enter 2024, 2025, 2026 or 2027 on Dashboard.
The selected year is saved in localStorage and all pages use that year.

Reports:
Reports page includes model-wise report, monthly report, Print Report and CSV Export.

IMPORTANT:
All numeric values are demo/sample data for an academic/project dashboard. They are not claimed to be official Royal Enfield sales figures.
